# Changelog

Todas as alterações relevantes deste projeto devem ser registradas neste arquivo.

## [0.1.0] - 2026-06-10

### Adicionado

- Estrutura inicial da documentação profissional do repositório.
- README com descrição, instalação, execução e organização do projeto.
- Arquivos de contribuição, conduta, segurança e licença provisória.
- Templates de issue e Pull Request.
- Documentação complementar em `docs/`.

### Observado

- Projeto institucional estático em HTML, CSS e JavaScript.
- Backend reservado para crescimento futuro, sem implementação executável no estado atual.
- Vídeo institucional grande deve ser tratado com Git LFS, compressão ou hospedagem externa antes de publicação definitiva.
